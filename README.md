# Результат работы

Отчёт по прибыли и премиям по закрытым заказам.

Данные в каталоге `data` зашифрованы: AES-256-CBC, ключ выводится из пароля
через PBKDF2-SHA256 (200 000 итераций). Пароль у каждого квартала свой,
расшифровка целиком в браузере — на сервере пароля нет.

Открывать через `index.html`: выбрать год и период, ввести пароль.

Сборка и публикация: `docs/pub-результат.py` в рабочем проекте.
